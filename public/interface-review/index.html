P01
HighAccessibilityEvery route

Make the global chrome semantically complete.

The header and footer are repeated everywhere, so one careful repair removes unnamed controls, undersized social targets, duplicate page headings, and an invisible focus path at once.

Current evidence

  • Logo, LinkedIn, and Email links expose no accessible name in the runtime tree.
  • Social targets render at 36 × 36 px.
  • The header name is an h1, producing two h1s on all 71 routes.
  • The visually hidden Home header remains in the accessibility tree and tab order.

Proposed implementation

  • Add explicit link names; mark child icons decorative.
  • Raise icon buttons to 44 × 44 px.
  • Render the brand name as non-heading text.
  • Apply inert and aria-hidden while the Home header is off-screen; add a focus-revealed skip link.

src/shared/layout/header.tsx:44 · footer.tsx:11 · button.tsx:27 · app/layout.tsx:94

P02
HighLayout70 inner routes

Let the mobile header wrap instead of clipping.

At 320 px the tagline extends to x=323.5 while the content viewport ends at x=305. The fixed header hides the final words without making the overflow scrollable.

Current evidence

src/shared/layout/header.tsx:57–77 keeps the identity block from shrinking. Runtime measurement: tagline width 255.5 px from x=68 to x=323.5 inside a 305 px viewport.

Proposed implementation

Give the identity column min-w-0, cap the tagline to the remaining inline space, let it wrap to two lines, and let the non-Home spacer derive from the header’s mobile height.

P03
HighLayout25 Lab details

Keep every source tab and Copy action reachable at 320 px.

The tab row is a no-wrap flex layout inside an overflow-hidden shell. On four-file specimens the Copy button lands as far right as x=460 and cannot be reached.

Current evidence

Confirmed on 25 Lab details. Examples: Radial Progress, Sparkline, Color Shifting, Masked Heart, Animated Circuit, Shimmer, and every multi-file dispersion specimen. src/features/lab/exhibit-code.tsx:33–80.

Proposed implementation

Make the file tabs a horizontal scroller with a visible continuation cue, reserve a 44 px sticky trailing zone for Copy, and keep the code pane’s own horizontal scrolling independent.

P04
HighTypographyLab + project details

Stop truncating previous and next destinations.

Adjacent-item navigation intentionally applies truncate at mobile widths, but offers no tooltip, disclosure, or alternate visible route to the full project or specimen name.

Current evidence

Visible examples include “Bookmark Landin…” and “Loopstudio Landin…”. The same root pattern repeats in Lab. src/app/projects/[slug]/page.tsx:126,141 and src/app/lab/[slug]/page.tsx:133,148.

Proposed implementation

Stack previous and next as full-width navigation cards below 480 px, remove truncate, and allow title wrapping with text-wrap: pretty. Keep the split desktop layout.

P05
HighWriting + Layout1 post · shared guardrail

Turn raw URLs into readable destinations.

Three bare React URLs create 34 px of page-level horizontal overflow at 320 px and are needlessly hard to scan or understand in a screen-reader link list.

Current evidence

content/posts/frontendmentor-development-process.mdx:233–235 renders raw links up to 473 px wide. The page is the only route with document-level horizontal overflow in the 320 px scan.

Proposed implementation

Write descriptive Markdown links—“Understand your UI as a tree,” for example—and add overflow-wrap: anywhere to the shared MDX anchor as a resilient last line of defense.

P06
HighAccessibility + Type2 craft essays · shared controls

Make playground controls semantic and touchable.

The controls show labels visually, but the labels are not bound to the range inputs or select. Range inputs render 8–16 px high, and the 14 px mobile select triggers iOS focus zoom.

Current evidence

Runtime accessible snapshots announce sliders by value rather than “Translate X,” “Input range minimum,” or “Scale.” The component also introduces h3 immediately after the page h1. range-control.tsx:19–53, dual-range-control.tsx:63–107, select-control.tsx:15–34, playground.tsx:26–33.

Proposed implementation

Generate stable IDs, bind every label, give the dual range two explicit names, expand the input box to 44 px while keeping a restrained visual track, hold selects at 16 px on mobile, and make the playground heading level configurable (h2 here).

P07
HighAccessibility + UI22 Labs + craft previews

Give motion a pause and a reduced-motion contract.

The Lab’s purpose is motion, but demonstrating motion does not require forcing it. Eighteen sandbox specimens and four native specimens move without a reduced-motion guard; “Auto” specimens offer no pause. Craft preview videos autoplay and loop without controls.

Current evidence

Missing guards include Animated Circuit, Bounce, Shimmer, Rocket Ship, the dispersion sequence, Timer, Fey Chart, Like Button, and Dot Grid. Craft autoplay is at craft-section.tsx:68–80 and craft-list-page.tsx:55–67.

Proposed implementation

Add a shared specimen motion toolbar for Pause/Restart, default Auto specimens to paused when prefers-reduced-motion: reduce, gate native loops in JS, and render the craft poster instead of autoplay under reduced motion. Keep motion state visible in text.

P08
HighColors4 long-form routes

Darken the accent only enough to pass body-link contrast.

The current primary renders as #CB5343 on #FAFAFA: 4.14:1 for 18 px regular links, below the required 4.5:1. The same pair appears 17 times across the published craft essays and posts.

Current evidence

Measured from rendered pairs, not token assumptions. The shared anchor applies text-primary at src/mdx-components.tsx:78–84; the light token is 7 57% 53% in src/app/globals.css:22.

Proposed implementation

Keep hue and saturation; change only lightness to 7 57% 50% (#C84837). That is the smallest whole-percent adjustment that passes on #FAFAFA at 4.53:1 and improves white-on-primary to 4.73:1.

P09
HighColors30 Lab details

Use Shiki’s high-contrast GitHub themes.

The GitHub Light syntax theme renders #E36209 on white at 3.49:1 for 13 px code. The exact failing pair appears 197 times across 30 Lab routes.

Current evidence

Lab source uses github-light/github-dark at src/features/lab/exhibit-sources.ts:58–61. MDX uses the same pair at contentlayer.config.ts:149–152.

Proposed implementation

Reuse Shiki’s installed github-light-high-contrast and github-dark-high-contrast themes. This is a two-value correction at the shared source—no per-token overrides and no new color notation.

P10
MediumLayout + Writing + UIHome + Work index

Give every Work card visible identity.

The Work index is eight screenshots with no visible titles, summaries, or technologies. The only explicit affordance is an arrow that appears on hover, so touch users must infer each project from a tiny website capture.

Current evidence

src/app/projects/page.tsx:38–69 and project-section.tsx:44–75 render image-only cards. The constants’ descriptions repeat Frontend Mentor challenge briefs rather than naming Robert’s implementation or outcome.

Proposed implementation

Add a compact title, one outcome-oriented sentence, and 2–3 tags below each image. Keep the entire card linked, make the affordance persistent on touch/focus, and replace transition-all with explicit color/box-shadow/transform transitions.
